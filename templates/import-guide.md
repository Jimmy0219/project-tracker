# 請幫這個專案建立進度檔（Project Tracker）

請依下面四個步驟，替目前這個專案建立進度檔，並設定好之後的進度回報方式。

## 1. 先了解專案

看下列資料，歸納出專案的目標、現況與接下來要做的事（大檔案用 Grep／tail 抽重點，不要整份讀完）：

- **專案文件**：README、CLAUDE.md、TODO、筆記、`docs/`、計畫書或交接文件
- **git 紀錄**（若有）：最近約 30 筆 commit（含日期）、`git status`
- **過去的 Claude Code 對話**：`~/.claude/projects/` 底下對應這個資料夾的 `*.jsonl` 與 `memory/`，優先看最近幾個 session；在處理其他資料夾專案的部分不要算進來
- **程式碼**：`TODO`、`FIXME` 與明顯未完成的地方

## 2. 在專案根目錄建立 `PROGRESS.md`

格式請**完全照下面**（Project Tracker 會解析這個檔案）：

```markdown
---
project: 專案名稱（簡短）
status: in_progress
---

## 目標
一句話：這個專案最後要做到什麼

## 現在
一句話：目前做到哪

## 任務
- [x] 已完成的任務
- [ ] 下一個要做的任務
- [ ] 之後要做的任務

## 等你決定
- 需要我回答的問題？

## 紀錄
- 2026-01-01 12:00 發生了什麼
```

寫的時候請遵守：

- **每一項 20 字以內**，讓人一眼看懂；細節不要寫進來
- **任務** 3～10 項，依執行順序排列；第一個未勾選的就是「下一步」
- 不確定的推論、需要我決定的事放進 **等你決定**；沒有就寫「（無）」
- **紀錄** 從 git 與對話還原 3～8 個重要里程碑，由舊到新，最後加一行「依匯入說明建立進度檔」
- `status` 只能是 `in_progress`（進行中）、`paused`（暫停）、`done`（完成）
- 全部用繁體中文（台灣用語）；不要寫入金鑰、密碼或個人隱私

## 3. 在專案的 `CLAUDE.md` 加入回報規則

在專案根目錄的 `CLAUDE.md`（沒有就建立）**加入**下面這段，讓之後每個 Claude Code session 都會照做：

```markdown
## 進度回報（Project Tracker）
- 開工先讀 `PROGRESS.md`，從「任務」中第一個未勾選的項目接著做
- **每完成一項任務就立刻更新 `PROGRESS.md`**：勾選該任務、改寫「現在」、在「紀錄」加一行（YYYY-MM-DD HH:MM 做了什麼）
- 發現新任務就加進「任務」；需要我決定的事寫進「等你決定」，我回答後再移除
- 每一項保持 20 字以內
```

## 4. 完成後告訴我

回報：「`PROGRESS.md` 已建立，請把它拖進 Project Tracker」，並簡短列出你不確定、需要我確認的地方。

除了 `PROGRESS.md` 與 `CLAUDE.md`，這次不要修改專案裡的其他檔案。
